## 統計の計測箇所と定義

| 統計 | 計測箇所・定義 |
| --- | --- |
| 初期LIFE・先攻ターン | `startGame()`：シーズン戦のみ初期化。先攻なら1、後攻なら0から開始。 |
| 自分の行動ターン | `prepareNextTurn('player')`、`beginExtraTurn('player')`。CPUターンを除外。 |
| LIFE与ダメージ | `changeLife()`：防衛線処理後の実減少を敵LIFE残量で上限処理。戦闘・能力の発生元カードと所有側を明示。 |
| 敵ユニット与ダメージ | `damage()`：ダメージ軽減・戦闘無効を適用後、減少前パワーを上限として集計。致死は実際に失われたパワー相当量を計上。反撃も自軍ユニットの与ダメージに含む。 |
| ユニット能力 | `executeActions()`から発生元を明示して共通ダメージ関数へ渡す。スペル・LMの直接ダメージは除外。 |
| 敵ユニット撃破 | `destroy()`：実際の破壊のみ。トークンもユニットとして数える。同一実体の蘇生後の再破壊はWeakSetで除外。破壊の原因を問わず敵の破壊イベントを計測。 |
| 敵LM破壊 | `destroyLandmark()`：実際の破壊のみ。同一実体の再破壊も除外。 |
| 防衛線突破 | `changeLife()`：亀裂1→突破2の初回のみ、レーン番号で記録。 |
| 被LIFEダメージ | `changeLife()`：自傷・敵効果も含む実減少の累計。回復では減算しない。 |
| 最終LIFE・生存・無傷 | `handleSeason1BattleEnd()` → `recordSeasonBattle()`：ユニットのみ数え、戦闘統計を一度だけ確定。 |

ログ文字列を解析していません。計測用のWeakSetは保存から除外し、カード実体を変更しません。計測と計算と表示をそれぞれ別の関数に分離しています。

## 計算式とランク

定数：`SEASON1_SCORE_RULES`、`SEASON1_RANKS`。

- 勝利：1,000。
- スピード：`max(0, min(1000, 1200 - playerTurns * 100))`。
- LIFE：`min(20, max(0, remainingLife)) * 30`。
- ユニット与ダメージ：`min(500, unitDamage * 10)`。
- 戦術：`min(500, enemyUnitKills * 40 + enemyLandmarkKills * 60 + breachedLanes * 50 + survivingUnits * 20)`。
- 無傷勝利：被LIFEダメージ0で勝利した場合300。
- 敗北戦は与ダメージ・戦術のみ加算し、生存ユニットの得点は除外。
- 3戦クリア：各戦合計に2,000追加。最大3,900／戦、13,700／シーズン。
- S：11,000以上「暁の英雄」、A：9,000以上「王都の守護者」、B：7,000以上「歴戦の騎士」、C：4,500以上「生還者」、D：それ未満「駆け出しの兵士」。敗北はFAILEDでランクなし。

## 保存と互換性

既存キー`crossfort_season1_v1`は従来の進行を維持。新キー`crossfort_season1_scores_v1`に以下を保存します。

- `run`：進行中の各戦統計・確定スコア・現時点合計・使用デッキのコピー。
- `last`：最終挑戦の全統計・合計・ランク・完了日時。
- `best`：クリアした最高得点の記録と使用デッキ。
- `history`：終了した挑戦の記録。
- `attempts`、`clears`：新規挑戦回数と新実装以降のクリア回数。

再挑戦は`run`のみ初期化し、最高記録・過去戦績・回数を保持します。失敗では最高クリア記録を更新しません。終了確定は重複実行しても一度だけ。

旧セーブからの途中続行は読み込めます。ただし過去の戦闘の統計は復元できないため、以降の計測分のみ加算し、その旨を画面に表示します。以前のクリア回数は旧データに数値がないため遡って作りません。

## リザルトの構造・演出

ブランド・シーズン名 → CLEAR/FAILED → 合計スコア → ランク／敗北地点 → 3戦の得点と完全制覇ボーナス → 小さな焚き火 → メッセージ・最高記録・回数 → 戦績詳細／再挑戦／ホーム。

背景と焚き火はCSSで描画し、画像サービスへの実行時依存はありません。炎の輪郭は段状、柔らかい光だけグラデーションです。FAILEDは暗く、炎を小さく低彩度にします。結果・ランクのフェード、700msのスコアカウント、低頻度の火の粉を使用。各挑戦のカウントアップは同一ページ内で一度だけ。`prefers-reduced-motion`で停止します。

詳細はネイティブdialogで表示し、戦闘タブ、統計、6カテゴリ内訳を掲載。閉じる・Escapeに対応し、内部スクロールを許可。小さい高さの画面では結果画面自体もスクロールでき、操作ボタンに到達できます。

第1・第2戦は従来のストーリーへ進み、第3戦は従来のエンディングを最後まで表示した後に結果へ進みます。

## 残る課題

- localStorageは端末・ブラウザ単位です。別端末への同期はありません。
- 旧セーブの未計測分は遡及計算できません。
- 保存容量不足時の永続化は既存と同様に失敗し得ます。
- 実端末での追加確認、全カード組み合わせの網羅は今後の確認範囲です。
