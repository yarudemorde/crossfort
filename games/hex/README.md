# CROSSFORT HEX — 固有キャラクター戦術バトル v2.0

クロスフォート戦記の世界で、固有名を持つ兵士を編成してCPUと戦うブラウザゲームです。公開先は既存の `/crossfort/hex/`。リポジトリルートのカードゲームとは独立しています。

## 開発・検証

Node.js 22以降。

```sh
cd games/hex
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
```

`dist/` は静的配信できます。リポジトリのPagesワークフローはルートのカードゲームとHEXを同じ成果物に梱包します。HEXは相対アセットURLを使用します。

## 遊び方

1. ホームで所持兵を確認し、1〜6名・コスト10以内で編成します。
2. 戦場・サイズ・先攻・シードを選び、本城周囲の6マスに配置します。ドラッグ、または部隊→配置先のタップで入れ替えられます。
3. 部隊を選択し、金色のマスへ移動します。その場で攻撃することも可能です。
4. 赤い攻撃対象を選び、予測ダメージ・反撃を確認して攻撃します。攻撃せず手番を終えることもできます。
5. 敵本城HP15を削るか敵兵を全滅させると勝利。本城破壊時の降伏兵1名に勧誘を試み、生存味方1名を強化します。戦死した味方は勝利確定時に永久喪失します。
6. 敗北なら戦闘前の配置、またはホームに戻れます。所持キャラクターのレベル・戦績は戦闘前のままです。

マップは1本指・マウスドラッグで移動、2本指ピンチ・ホイールで拡縮できます。パネルの開閉や部隊選択でカメラを自動変更しません。キーボードでは盤面マスをTabで選び、Enter/Spaceで操作できます。

## 保存

IndexedDBに所持データと非公開の戦闘スナップショットを分けて保存します。操作結果は保存成功後に画面へ返します。勝利と報酬開始は同じトランザクションで確定し、リロード後は戦闘または未完了報酬を再開します。複数タブからの同時更新はリビジョン照合で拒否します。

データは使用中のブラウザ・端末・サイトの配信元ごとに保存されます。端末間同期はありません。ブラウザのサイトデータを消去すると所持データも失われます。旧カード版の対戦データを新しいロスターに変換しません。破損セーブは上書きせずエラーにします。

## 構成と暫定項目

- `src/character/`: ロスター、戦闘、CPU、報酬、保存、Worker、可視演出フレーム
- `src/app/CharacterApp.tsx`: フェーズ画面と操作
- `src/components/character/`: 観測情報だけを描く盤面
- `data/ruleset.characters.json`: 職業、成長、編成、勧誘等の調整値
- `data/presentation.settings.json`: 移動・戦闘演出の時間とカメラ操作
- `docs/GAME_SPEC.md`: v2ルールと確定・暫定の区分

初期名・所属の配分、CPU編成、地形補正、待機、敵全滅勝利、勧誘1回、ローカル保存は仕様書の暫定値です。経験値・スペル・手札・資源・建設・領土収入・ユニーク職・対人戦は使用しません。将来職用の拡張は独立した職業定義を追加して実装できます。

旧カード版のソースとテスト、画像、マップデータは参照用として残しています。旧仕様書は `docs/archive/` に退避しました。旧テストは旧ルールの参照回帰確認であり、v2の受入試験とは分けています。
