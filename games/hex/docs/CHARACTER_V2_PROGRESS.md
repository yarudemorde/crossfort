# 固有キャラクター戦闘 v2.0

標準エントリーを新モードへ切り替えました。旧版のカード・手札・資源・建設は標準ゲームでは使用しません。

ロスター・編成・配置・交互戦闘・CPU・勝敗・勧誘・強化・帰還・永続保存を接続しています。移動は各マス、戦闘は攻撃・HP減少・反撃・死亡の順に、プレイヤーの観測だけで演出します。非公開戦闘スナップショットをWorker内で保存し、勝利と報酬開始を一括確定してから画面へ返します。再読み込み時は未完了の戦闘・報酬を再開します。

検証内容・実行コマンド・環境上の範囲は `ACCEPTANCE_V2.md` と `README.md` を参照してください。スマホ実機のタッチ・性能測定はこの環境から実行できず、ブラウザ内の指定サイズ検証とジェスチャー自動試験で代替しています。
