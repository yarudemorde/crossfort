# 固有キャラクター戦闘 v2 実装状況

作業ブランチには独立した試験用画面 `?mode=characters` を追加しています。公開版の切り替えは行っていません。

実装済み：初期ロスター、個体差と成長、補充・除隊・名前変更、編成、配置、6マップ、交互手番、移動後攻撃、HP・攻撃・反撃、視野・霧、CPU、敗北後の配置への復帰、結果・勧誘・強化、IndexedDBによる報酬保存と再開。Workerはプレイヤーの観測のみ返し、移動は可視の途中マスごとの画面状態を返します。旧HEXとは別モードです。

現段階のブラウザ確認：PCのプレビューで初期9名、編成、タップによる配置、戦闘開始、移動、CPU手番、敗北、配置への復帰を確認。勝利後の処理はセッション境界と純粋関数の自動テストで確認しています。

公開前の未完了項目：攻撃・反撃・死亡の構造化された順次演出とログ、ゲーム終了直前・報酬保存中の中断復旧の保証、実ブラウザでの勝利・勧誘・強化・再読み込みの一連の確認、スマホのドラッグとピンチの実機検証、幅広い画面サイズ・アクセシビリティ検証、説明書のv2への更新、AC-01〜28の全件検証。勝利結果の確定前にブラウザが終了した場合、戦闘結果を失う可能性があります。スマホ配置ではタップ操作を使用できますが、スワイプは未検証です。

CPU試作は2種類×3サイズ×先後×3シード（6名編成）で合法手による決着を確認しました。それ以外のシードでの停滞の可能性は残ります。

未完了機能を理由に、現行の `main` とGitHub Pagesは旧HEXを維持します。実際の公開版への置換は、上記の完了と通し検証の後に行ってください。
