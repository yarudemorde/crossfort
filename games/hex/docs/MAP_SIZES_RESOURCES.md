# マップサイズ選択・資源公開上限

2026-11-03。対象 `games/hex/`。ユーザーの追加仕様で承認された2項目のみ、ルール/データを拡張しました。

## 実装

| サイズ | 半径 | 実タイル | 初期選択 |
| --- | ---: | ---: | --- |
| 小 | 3 | 37 | — |
| 中 | 4 | 61 | ○ |
| 大 | 5 | 91 | — |

- 種類（渡河戦/山岳戦）とサイズを別の状態で管理し、6つの具体マップIDへ解決します。中は既存の `crossing` / `highlands`、追加サイズは `-small` / `-large`。
- `data/maps.prototype.json` はバイト単位で維持。小・大の4配置を `data/maps.additional.prototype.json` に追加。地形はデータとして編集できます。
- 本城は `(−半径,0)` と `(半径,0)`。領土1は重ならず、周辺と進軍路を確保。追加配置は左右対称です。全地形は従来の6画像を使います。
- UIのカタログ生成は公開属性だけを許可し、地形配列を出力しません。観測・視野外CPU・霧の既存処理を維持します。
- カメラは公開座標から全タイルの頂点/枠線を含む外周を計算。初期表示と「全体」は、その外周がマップ操作ボタンの領域を避けて収まる倍率/位置です。初回は描画前に適用します。
- SVGはCSSピクセルの座標系を維持。UI開閉時に自動で再中央寄せを行わず、手動の位置・倍率を保持します。ドラッグ・ピンチ・ホイール処理は継続。
- 再戦には既存の具体マップID/シード/先後を使います。記録保存にも具体ID・種類ID・サイズ・半径を含めます。
